# Why there is no front end

The work is a set of records: where a sample is, who took it, how much remains and what must be checked. The operator asks in plain language and the agent runs a command. The same database produces read-only inventory lists, custody records and stocktake sheets.

A browser system supplies visual freezer maps, mobile or offline capture, concurrent editing, authenticated approval, barcode scanning and label printing. This base supplies none of those. It also has no sensors, automatic alarms, instrument connection or file comparison. Enterprise DNA scopes those features in a customised version where required.

The storekeeper must confirm physical moves and measurements. An agent cannot observe a freezer or verify that a vial moved. Never let an inferred quantity or location become a recorded fact.

For a single local operator, PGlite is a small start. A shared deployment needs secured Postgres, authenticated access, backups and tested recovery. Static HTML documents are files, not an application or an access-control system.
